# Nexus layout preview

`home.html` and `home.png` show the existing native three-card layout using the
actual Nexus wallpaper and icons shipped with the test build. The preview uses
browser fonts; spacing and font rendering on Switch can differ. Storage,
firmware and running-build values in the image are examples, not device readings.

The app itself is native C++/NanoVG, not an HTML application.
